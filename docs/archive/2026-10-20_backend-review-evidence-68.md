### P2-125: Python SDK README 用一个**无日期的活体读数**（跨项目返回的 distinct project 数）支撑「`list_observations` 会放宽项目过滤」这个结论，而该读数**已经漂移**
- **Problem**: `python-sdk/cortex-mem-python/README.md`（及 `-zh-CN.md`）在论证
  「`list_observations` 是唯一一个项目过滤**放宽**而非**清空**的检索方法」时，给出的唯一**量化证据**
  是一个**没有测量日期**的活体读数：`GET /api/observations` 不带 `project` 时，在**一个 100 条的单页**里
  返回了 **16 个不同项目**的数据。该数字是**库内容的函数**（随项目数增长而变），写在一段
  **现在时**的叙述里而无日期，读者只能当作**当前值**。
- **Evidence**:
  - **2026-10-20 活体复测（连测三次，稳定）**：`GET /api/observations?limit=100` →
    每次均返回 **100 条**、其中 distinct `project` 为 **15** 个（**不是 16**）。
  - **对照（说明该读数必然漂移）**：`SELECT count(DISTINCT project_path) FROM mem_observations`
    在同一库上实测为 **2276** —— 即「库里共有 2276 个项目」，而单页 100 条只覆盖到其中 15 个。
    库在持续增长（本仓库的 E2E 每次都会新建 `/tmp/claude-mem-test-*` 项目），故这个数字**必然继续变**。
  - **反向对照（证明读数不是探针假象）**：同一端点**带默认 limit**（20）时返回 20 条、distinct 为 **4**；
    说明读数随取回的条数变化，与「单页覆盖 15 个项目」一致。
  - **结论本身仍然成立**：`list_observations` 省略 `project` 时确实**不发送** `project` 参数
    （Python 侧 `if project:` 把它转成省略；四家 SDK 皆然），后端随即返回**该实例上全部项目**的观测。
    漂移的只是那一个**具体数字**，而它恰恰是无日期的。
- **Impact**: 文档的**论点**（跨项目放大 → 多租户部署下是跨租户外泄）**不受影响**，仍完全成立；
  受影响的是**证据的时效性**：一个会随库增长而变、却没有日期的数字，被写成了当前事实。
  同类问题在本仓库已按「凡读数必带日期」的纪律处理过（见 P2-90 的 Go README 测试计数）。
- **Fix（已实施，双语，纯文档、零行为变更）**：给该读数**加上测量日期 2026-10-20**、
  更正为当天的实测值 **15**，并**明写「该数字随数据库的增长而变，故它是带日期的实测值而非实时值
  —— 要点是跨项目的广度，而不是确切数字」**。
- **Not fixed（待用户决策）**: 让后端**要求** `project`、或让「缺省 project 时收窄到实例范围」，
  属**对外行为契约变更**（会改变现有调用方的返回集），按既定纪律**只记录不单方面实施**。
  **三选一**：
  ①**只更正文档**（**已实施**）；
  ②**后端把 `project` 变为必填**，或缺省时按实例/租户边界收窄（**行为变更**，需评估现有调用方）；
  ③**SDK 侧显式提示**：四家在 `list_observations` 未传 `project` 时**不改变请求**、但**明确告警**
    「本调用将返回该实例上**所有项目**的观测」——零行为变更，可与①并存。
  **任一选项都应先补后端对 `GET /api/observations` 缺省 `project` 路径的测试**（现为零覆盖）。
- **Status**: ⏸ **是否要让「省略 project 就跨项目返回」这件事在行为层收敛留待用户决策**（属对外行为契约变更）—— **失实陈述本轮已修**（双语，纯文档）：那个**无日期**的活体读数（16 个 distinct project）**实测已漂移到 15**（连测三次稳定；库里共有 2276 个 project，该读数必然继续变），现已**加上测量日期 2026-10-20**、更正为当日实测值，并明写「随数据库增长而变、带日期的实测值而非实时值」。**三选一见归档正文**。 条目全文已逐字迁入 [`…-68.md`](../archive/2026-10-20_backend-review-evidence-68.md)（第 368 轮）。
